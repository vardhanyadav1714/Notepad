Notes 1.4: safer gestures and continuous pages

Latest build: Notes 1.5 — behaviour checked directly on the connected Samsung tablet, automatic theme adaptation and page creation.

Version 1.4 (20) addresses accidental writing during pinch gestures, removes unnecessary page redraw work during zoom, and makes multiple pages and landscape controls accessible from the editor. Collaboration remains available in the header.

What changed

AreaBehaviour
Pinch and inkA finger stroke stays provisional until the touch sequence ends. The second finger cancels provisional ink, erasing or selection movement. Multitouch stays latched until every finger lifts, including a quick second-finger down/up and different finger-lift orders. Android cancellation discards the provisional edit. S Pen input retains priority over palm contacts, pressure and tilt samples.
CameraZoom is bounded to 15–600% of the fitted document width. Very close fingers do not generate unstable zoom ratios. Non-finite transforms are rejected. Combined pinch/pan keeps the document point under the fingers stable, and navigation keeps the document reachable. Fit-to-width is available in the zoom pill. Keyboard height changes retain the page origin; rotation preserves relative zoom and the top anchor.
Drawing workCompleted page commands live in retained graphics layers. Zoom changes the layer transforms; it does not regenerate every completed stroke or rich-text layout on each gesture frame. Text layouts use a bounded 128-entry cache keyed by content and typography. The viewport composes visible pages and adjacent pages rather than the entire notebook. Images and PDF backgrounds load off the UI thread.
Multiple pagesPages form a vertical document with small gaps, centred paper and page counts. Ink/text/image coordinates remain local to their original pages, preserving saving, export, selection and collaboration. Add a portrait or landscape page from Insert; an Add page control follows the last page. The Pages overview contains real miniature content, navigation, duplication, reordering and deletion.
Editor layoutThe editable title is in the compact header. Insert uses the plus control. Tool settings open on demand. Landscape exposes colour, easy writing pad, automatic shape correction, zoom lock and pages directly in the handwriting row. The text toolbar uses more of the available landscape width while retaining formatting, lists, alignment and indent controls.
Dark-paper highlighterHighlighter strokes remain visible on black paper using transparent source-over rendering. Light paper and imported PDFs retain multiply blending so black text remains readable. The same paper-aware rule applies to live ink, retained pages, page previews, colour picking and PNG/PDF export.
Existing featuresThe pen styles, pressure-sensitive strokes, erasers, mixed lasso selection, text formatting, images, PDF annotation, writing pad, recording, saving and exports remain. Room creation/join, ink synchronization, reconnect and peer-aware undo use the existing collaboration service.

Validation

A physical device performance check is still needed before claiming consistent 60/120 Hz rendering. This reconstruction does not implement every Samsung Notes service or private file format.

References and compatibility

The user's Samsung Notes portrait/landscape screenshots guided page presentation and toolbar placement. Official Samsung material confirms two-finger zoom, handwriting tools and page styles: Samsung handwriting guide, Samsung Notes guide, and Galaxy Z Fold6 manual. The earlier static APK resource inspection remains documented in the reconstruction report; no Samsung runtime or proprietary source was copied.

Collaboration is ink-only, as previously implemented; text, images, recordings and imported PDF backgrounds remain local. Same-stroke concurrent edits still use the existing whole-canvas protocol. The production endpoint and invite URLs are unchanged. See the 1.3 editor and collaboration report for those details and the remaining Samsung-specific gaps.
