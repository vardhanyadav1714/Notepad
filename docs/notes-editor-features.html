Notes 1.3: more editing tools, collaboration retained

Latest build: Notes 1.4 — gesture fixes, continuous pages and landscape controls.

Version 1.3 (19) continues the Samsung Notes reconstruction with mixed-content selection, non-destructive image crop/rotation, and an automatically advancing writing pad. The existing collaboration service and message types remain in use.

Editor additions

FeatureImplemented behaviour
Mixed selectionLasso or rectangle-select ink, text boxes and images together, including partial-selection and ink-only options. Move, resize, copy, cut, paste, duplicate and delete the group, with document undo/redo. Rich text and checklists retain their content; pasted images receive independent files so deleting the source note does not remove the destination image. Clipboard content remains app-local. Rotation/flip of a mixed group containing text or images is disabled; individual images have their own rotation control.
ImagesNon-destructive crop on all four edges, a rendered crop preview, reset crop, and 90-degree rotation. Select an image with the lasso, open Selection options → Edit image, then use Crop or Rotate. The same crop and rotation are used on the page, in thumbnails and in image/PDF export. Crop edits are one undoable operation; the original image file is retained.
Writing padThe magnified pad advances when a completed pen stroke reaches its right-hand threshold; it wraps to the next line near the page edge. Automatic advance can be disabled. Drag the highlighted target rectangle on the main page to reposition the writing area. Explicit advance, next-line and undo remain available.
Document persistenceVersion 4 documents save image crop/rotation and the note’s collaboration room. Earlier version 3 documents and legacy stroke arrays remain readable. Notes reopen their saved room; Leave room removes that association. Document undo does not change room membership.

Collaboration preserved and repaired

The visible Collaboration button opens Create room, Join by code/link, Reconnect, Share invite and Leave room controls. The production endpoint remains wss://drawly.smartattendance.xyz/ws; invite links still use https://drawly.smartattendance.xyz/r/…. No worker deployment or production-room test was performed.

AreaChange
Connection timingExisting ink is published after the new room connects, rather than being sent prematurely and silently lost. Pending local edits are retained while disconnected and published on reconnect.
Socket lifecycleRoom subscriptions have generation guards. Removing an old subscription cannot close a newer room, and stale callbacks are ignored. Server close handshakes are acknowledged, interrupted connections retry, and the panel shows the actual connection state.
Stable stroke identityCanvas updates keep the original stroke ID instead of adding another participant prefix on every trip. Existing prefixed IDs remain accepted. Message names and fields stay compatible with the existing server.
Peer ink and undoReceived ink changes are rebased into document history, so local undo/redo preserves peer ink in the tested sequences. Pressure, tilt, timestamps, page identity, pen settings, erasing and selection transforms continue through the shared-ink messages.
Collaboration shares ink. Text, images, recordings and imported PDF backgrounds remain local, as before. The protocol still uses whole-canvas replacement for editing operations; this is not a CRDT and does not guarantee conflict-free simultaneous edits to the same stroke. All participants should use the updated app for the stroke-identity and undo fixes.

Remaining Samsung-specific gaps

This is not a complete or pixel-identical Samsung Notes clone. Samsung account/cloud, private .sdoc/.sdocx compatibility, AI services, image OCR, transcription, Office exports, widgets, screen-off memo and device-specific gestures are not implemented. Text remains positioned page content rather than a flowing Samsung document. Physical S Pen latency, biometric/microphone hardware and successful recognition-model download need device/network validation. Note locks remain device-authentication gates rather than encrypted files.
