Drawly 2.2: full screen and landscape

Compared against the installed Samsung Notes app on the connected Galaxy S22 (SM-S901E), Android 16/API 36, using a newly created reference note. Existing user notes were not edited. The reference fixture was moved to Recycle bin afterwards.

Samsung reference and Drawly

Validation

  • 26 JVM tests and the full 62-test Android suite passed on the dedicated 16 KB emulator.
  • 28 focused tests passed on the physical Samsung phone, covering gestures, ink visibility, pages, saving, themes, landscape controls and local TLS/WebSocket collaboration.
  • The final full-screen flow passed on both phone and tablet, including display rotation, text/handwriting switching, drawing, undo/redo, Back, status visibility, toolbar bounds and persistence. Phone rotation/night settings match their recorded initial values.
  • Seven release-variant workflows passed on a separate QA copy signed with the debug key. The production APK and bundle retain the existing drawly.jks signature.
  • The system-theme check now exercises six repeated text/handwriting mode switches before toggling themes. The earlier intermittent timeout did not recur in the full suite or focused phone/release checks; this is regression evidence rather than proof of its original cause.
  • Lint and release vital lint passed: 0 errors, 83 warnings and 3 informational findings. The collaboration worker passes strict TypeScript checking with npm run typecheck.

Android 16 ignores app-requested orientation on large screens. The final full-screen test rotates the display through the system, as a user would, and restores its original rotation settings. Captures wait for window events to settle rather than recording the rotation animation.

Before public rollout

The signed build is prepared for Play internal testing, not a claim that every production condition has been verified. Confirm the upload certificate and version code in Play Console, complete the applicable listing/privacy declarations and review the Play pre-launch report.

The live app-link association currently trusts the two earlier certificates, not the new direct-APK certificate above. The worker source now adds this certificate while retaining both live certificates; that source update has not been deployed. Verify Google's Play app-signing certificate separately, since Google may sign delivered APKs with a different key. Existing clients and live rooms were not changed during this review.

The installed original 1.4 package was left intact. Notes Preview was updated without clearing its data. A direct production APK can update an existing installation only when their signing certificates match; do not uninstall an existing notes app to work around a signature mismatch.

The S22 has no S Pen digitizer. Injected pressure/palm tests cover the input pipeline, not physical S Pen latency. Microphone hardware, downloaded recognition models, biometric prompts, every Android/OEM version and a universal frame-rate guarantee are outside this review. Collaboration still synchronizes ink/canvas state; text, images, PDFs and audio are not synchronized, and whole-canvas conflicts retain the existing last-writer behaviour.
